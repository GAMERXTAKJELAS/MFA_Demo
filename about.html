MFA Project MFA

About this project

Project MFA is a practical demonstration of Two-Factor Authentication (2FA) using an Out-of-Band (OOB) delivery channel. Instead of relying on a password alone, the system sends a time-limited one-time code to the user's Telegram account, so a stolen password alone isn't enough to break in.

How it works

  1. User logs in with a username and password.
  2. A cryptographically secure 6-digit code is generated and sent via the Telegram Bot API.
  3. The code expires after 3 minutes and is deleted immediately after use, preventing replay attacks.

Built with

Python Flask Telegram Bot API HTML / CSS / JS
